# Safe Lock Navigation Menu

An animated full-screen navigation menu with a smooth open/close transition, inspired by luxury brand UI patterns. Built with vanilla HTML, CSS, and GSAP.

## Features

- Full-screen overlay menu with split-panel background animation
- Hamburger toggle that morphs into an X on open
- Staggered text reveal using GSAP SplitText
- Custom easing for polished motion
- Responsive layout with fixed navigation bar

## Tech Stack

- HTML / CSS / JavaScript
- [GSAP](https://gsap.com/) (SplitText, CustomEase)
- [Vite](https://vitejs.dev/) for local development

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later recommended)

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open the URL shown in your terminal (usually `http://localhost:5173`).

## Project Structure

```
├── index.html    # Page markup and menu structure
├── styles.css    # Layout, typography, and menu animations
├── script.js     # GSAP timeline and toggle logic
└── package.json  # Dependencies and scripts
```
